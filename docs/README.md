# CopilotKit + GitHub Copilot SDK demo gallery

**Watch a rich agent experience: CopilotKit UI ↔ AG-UI ↔ Python Copilot SDK.**

**[Watch the gallery in your browser](https://arlindnocaj.github.io/copilot-sdk-ag-ui-frontend-demo/)**.

Press **Play** for the 2:50 highlight; select **Full demos** to explore all twelve
patterns. No download, account, package installation or model login is needed.
The highlight has music; a silent version and all full recordings are included.
Nothing autoplays or phones home.

For offline viewing only, [download the ZIP](https://github.com/ArlindNocaj/copilot-sdk-ag-ui-frontend-demo/releases/tag/gallery-v10),
unzip it and open `index.html`. Keep the extracted folder together.

## Build your own

Application code and setup:
https://github.com/ArlindNocaj/copilot-sdk-ag-ui-frontend-demo

The recorded stack is TypeScript/React CopilotKit, AG-UI, Python Copilot SDK 1.0.14,
and Claude Sonnet 5 via Microsoft Foundry inference. It uses a custom configuration;
the sample application's account-based quickstart is a different setup.
Examples and tool data are synthetic. Watching is not a live agent or deployment.

## Hosting this gallery

GitHub Pages serves this folder from `main` / `docs`; `.nojekyll` keeps the files
unchanged. No backend, secrets or custom build step is required. Only viewer-facing
media and metadata are included, not raw captures, logs or development evidence.
